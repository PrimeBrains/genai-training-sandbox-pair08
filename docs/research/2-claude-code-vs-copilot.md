## 1. 基本的な概要・位置づけ

### Claude Code

- **提供元**: Anthropic
- **形態**: CLI ツール + IDE 拡張 + Web UI + Slack 統合
- **位置づけ**: AI 駆動のフルスタック開発プラットフォーム。単なる補完にとどまらず、ファイル読み書き・コマンド実行・複数ファイル編集・チーム協業まで対応するエージェント型ツール
- **設計思想**: セッションベースのステートフル設計。複雑なタスクを自律的に実行する

### GitHub Copilot

- **提供元**: Microsoft / GitHub
- **形態**: IDE 拡張（VS Code / JetBrains / Visual Studio / Vim 等）
- **位置づけ**: IDE に組み込まれた AI ペアプログラマー。コード補完・チャットによる開発支援が主
- **設計思想**: IDE 内でのリアルタイム補完を中心とした、低レイテンシな開発補助

## 2. 主な機能の比較

### コード編集・補完

| 項目 | Claude Code | GitHub Copilot |
|------|-------------|----------------|
| 補完タイプ | 確認ベースの提案（実行指示が必要） | リアルタイム自動補完 |
| 入力レイテンシ | 秒単位 | 数百 ms（IDE ネイティブ） |
| 複数ファイル同時編集 | ✅ | ✗（提案のみ） |
| コンテキスト範囲 | 全ファイル + 外部参照 | 現在ファイル + 開いているタブ |

### 分析・デバッグ

| 項目 | Claude Code | GitHub Copilot |
|------|-------------|----------------|
| 根本原因分析 | ✅ 深い推論・ログ収集まで対応 | △ 基本的な提案 |
| テスト生成 | ✅ 包括的なテストケース＋実行検証 | ✅ 基本的なテスト |
| セキュリティレビュー | ✅ 専用スキル対応 | △ パターンベース |

### セッション・コンテキスト管理

| 項目 | Claude Code | GitHub Copilot |
|------|-------------|----------------|
| セッション管理 | ✅ 複数セッション・フォーク可 | ✗ 単一セッション |
| コンテキスト保持 | ✅ プロンプトキャッシング | △ 基本的 |
| サブエージェント・並列処理 | ✅ | ✗ |

### 拡張性・カスタマイズ

| 項目 | Claude Code | GitHub Copilot |
|------|-------------|----------------|
| カスタムスキル | ✅ Bash / Python スクリプト | △ 拡張機能限定 |
| MCP 統合 | ✅ ネイティブ対応 | ✗ |
| フック機能 | ✅ Pre / Post コマンドフック | ✗ |

### チーム・エンタープライズ機能

| 項目 | Claude Code | GitHub Copilot |
|------|-------------|----------------|
| Slack 統合 | ✅ | ✗ |
| 監査ログ・コスト追跡 | ✅ 詳細 | ✅ GitHub ログ |
| SSO / SAML | ✅（Enterprise） | ✅（Enterprise） |

## 4. 料金・プラン

### Claude Code

| プラン | 月額（目安） | 特徴 |
|--------|------------|------|
| Claude Pro | ~$20 / 人 | 個人・高コンテキスト |
| Claude Team | $30 / 人（5 名以上） | チーム共有・監査 |
| Claude Enterprise | カスタム | SSO・専用サポート |
| API 従量課金 | トークン量による | 柔軟なコスト管理 |

- プロンプトキャッシングにより最大 90% のコスト削減が可能
- 参考: Haiku $0.80 / 1M トークン、Sonnet $3.00、Opus $15.00

### GitHub Copilot

| プラン | 月額（目安） | 特徴 |
|--------|------------|------|
| Individual | $10 / 人 | IDE 統合・基本チャット |
| Business | $19 / 人 | 監査・グループ管理 |
| Enterprise | カスタム | SSO・SCIM・専用サポート |

## 5. 得意・不得意なユースケース

### Claude Code が得意

- 大規模リファクタリング・複数ファイルの一括変更
- 複雑なバグの根本原因分析（ログ収集・実行検証含む）
- 設計相談・アーキテクチャ検討
- 自動化スクリプト・CI/CD パイプライン構築
- チーム開発・Slack 経由の非同期協業
- エンタープライズ向けのコンプライアンス対応

### GitHub Copilot が得意

- IDE 内でのリアルタイムコード補完
- 単純な関数・ボイラープレートの高速実装
- IDE を離れずに行う軽量な質問・解説
- 関数ドキュメントの自動生成
- GitHub PR / Issue との連携

## 6. 使い分けガイド

### 使い分け表

| 開発シーン | 推奨ツール | 理由 |
|----------|------------|------|
| コード補完・タイピング | **GitHub Copilot** | リアルタイム補完・低レイテンシ |
| 単一ファイルの実装（~50行） | **GitHub Copilot** | IDE 統合・高速 |
| 複数ファイルのリファクタリング | **Claude Code** | 複数ファイル同時編集 |
| 複雑なバグ修正 | **Claude Code** | 深い分析・実行検証 |
| 設計相談・アーキテクチャ決定 | **Claude Code** | 深い推論・複数案検討 |
| テスト生成（包括的） | **Claude Code** | 詳細ケース生成・実行検証 |
| 自動化・CI/CD 構築 | **Claude Code** | Bash・MCP・スキル連携 |
| チーム協業・Slack 通知 | **Claude Code** | Slack 統合・共有セッション |
| IDE 内の軽量な質問 | **GitHub Copilot** | IDE を離れず完結 |
| 初心者のコード学習支援 | **GitHub Copilot** | 補完で手法を学べる |

### 判断フローチャート

```
タスク開始
  │
  ├─[IDE でのリアルタイム補完が主]──→ GitHub Copilot
  │
  ├─[複数ファイルの編集が必要]────→ Claude Code
  │
  ├─[複雑な問題の分析・デバッグ]──→ Claude Code
  │
  ├─[自動化・チーム協業]──────→ Claude Code
  │
  └─[単純な実装・補助が欲しい]───→ GitHub Copilot（または併用）
```

### 推奨構成

| 規模 | 推奨構成 |
|------|---------|
| **個人開発** | GitHub Copilot（メイン）+ Claude Code（複雑な問題時） |
| **小〜中規模チーム** | Claude Code Team + GitHub Copilot Business（オプション） |
| **エンタープライズ** | Claude Code Enterprise + GitHub Copilot Enterprise |

### まとめ

- **GitHub Copilot** は IDE にシームレスに統合されたリアルタイム補完が強み。日々の実装作業の速度向上に最適
- **Claude Code** は複雑な問題解決・大規模変更・チーム協業・自動化に強みを持つエージェント型プラットフォーム
- **両者は競合ではなく補完関係**。IDE での補完は Copilot、深い分析や大規模タスクは Claude Code、という使い分けが現実的
